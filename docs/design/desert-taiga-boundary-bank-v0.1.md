## DTB01 — สัญญาณที่เพื่อนยังไม่พูด

**Domain:** `relationship_boundaries`  
**Discriminates:** Fennec Fox ↔ Lynx ↔ Wolverine  
**Measures:** `AFF + AGY`

เพื่อนคนหนึ่งเริ่มเงียบและถอนตัวจากกลุ่ม แต่ยังยืนยันว่าไม่มีอะไรเกิดขึ้น คุณรู้สึกว่ามีบางอย่างผิดปกติ คุณทำอย่างไร?

- **A.** ให้พื้นที่และสังเกตต่ออย่างเงียบ ๆ จน pattern ชัดพอ โดยไม่เข้าไปเปลี่ยนสถานการณ์  
  `AFF -0.8 ×1.0, AGY -0.4 ×1.0`
- **B.** ชวนคุยเรื่องเล็กที่ไม่กดดัน เปิดช่องให้เขาส่งสัญญาณกลับมาในจังหวะของตัวเอง  
  `AFF +0.4 ×1.0, AGY -0.4 ×1.0`
- **C.** พาเขาออกจากสถานการณ์ทันทีและจัดการสิ่งที่น่าจะเป็นต้นเหตุ แม้ยังไม่ได้รับคำขอ  
  `AFF -0.4 ×1.0, AGY +0.8 ×1.0`
- **D.** บอกตรง ๆ ว่าคุณสังเกตเห็นอะไร และชวนเขากำหนดด้วยกันว่าต้องการให้ช่วยแบบไหน  
  `AFF +0.8 ×1.0, AGY +0.4 ×1.0`

## DTB02 — ชื่อของคุณในบันทึกที่ผิด

**Domain:** `identity_expression`  
**Discriminates:** Caracal ↔ Lynx ↔ Moose  
**Measures:** `EXP + STR + RST`

ผลงานสำคัญของคุณถูกประกาศต่อสาธารณะ แต่คำอธิบายทำให้ตัวตนและเหตุผลของคุณผิดไปจากความจริง คุณแก้สถานการณ์อย่างไร?

- **A.** เก็บข้อเท็จจริงไว้กับตัวและถอนตัวจากพื้นที่นั้น คุณไม่ต้องการให้คำอธิบายของใครครอบครองความจริงภายใน  
  `EXP -0.8 ×1.0, STR -0.4 ×0.5, RST +0.0 ×0.5 probe`
- **B.** แก้เฉพาะประโยคที่สำคัญด้วยคำพูดสั้นและแม่น แล้วปล่อยให้ผลงานยืนด้วยตัวเอง  
  `EXP -0.4 ×1.0, STR +0.4 ×0.5, RST +0.5 ×0.5 probe`
- **C.** ขอให้แก้บันทึกอย่างเป็นทางการและวางมาตรฐานว่าคำประกาศแบบนี้ต้องตรวจสอบอย่างไรก่อนเผยแพร่  
  `EXP +0.4 ×1.0, STR +0.8 ×0.5, RST +0.5 ×0.5 probe`
- **D.** ใช้โอกาสนี้เล่าเรื่องทั้งหมดในแบบของคุณ เพื่อให้ทุกคนเห็นทั้งผลงานและตัวตนที่อยู่เบื้องหลัง  
  `EXP +0.8 ×1.0, STR -0.4 ×0.5, RST +0.0 ×0.5 probe`

## DTB03 — พื้นที่ส่วนกลางที่ถูกใช้เกินขอบเขต

**Domain:** `public_power`  
**Discriminates:** Cobra ↔ Moose  
**Measures:** `EXP + STR + RST`

กลุ่มหนึ่งใช้พื้นที่ส่วนกลางผิดจากข้อตกลงซ้ำ ๆ จนคนอื่นเริ่มเสียสิทธิ์ แต่กฎเดิมไม่ได้ระบุบทลงโทษไว้ชัด คุณเสนออะไร?

- **A.** ลดการใช้พื้นที่ของตัวเองและรอดูว่าความขัดแย้งจะคลี่คลายหรือมีข้อมูลเพิ่มหรือไม่  
  `EXP -0.8 ×1.0, STR -0.4 ×0.5, RST +0.0 ×0.5 probe`
- **B.** เพิ่มกฎถาวรที่ใช้กับทุกกลุ่มเหมือนกัน พร้อมกำหนดเขตและบทลงโทษมาตรฐาน  
  `EXP +0.4 ×1.0, STR +0.8 ×0.5, RST +0.5 ×0.5 probe`
- **C.** ประกาศว่าเกิดความเสียหายอะไร เส้นสุดท้ายอยู่ตรงไหน และผลที่เจาะจงจะตามมาหากเลือกข้ามมันอีก  
  `EXP +0.8 ×1.0, STR +0.0 ×0.5, RST +1.0 ×0.5 probe`
- **D.** เรียกแต่ละฝ่ายมาคุยและปรับข้อตกลงตามเหตุผลกับความจำเป็นของคนที่เกี่ยวข้อง  
  `EXP +0.4 ×1.0, STR -0.4 ×0.5, RST +0.5 ×0.5 probe`

## DTB04 — คำขอที่ยาวกว่ากำลัง

**Domain:** `care_community`  
**Discriminates:** Camel ↔ Reindeer  
**Measures:** `ALG + RST + CON`

คนใกล้ตัวขอให้คุณช่วยรับผิดชอบเรื่องหนึ่งตลอดหลายเดือน คุณช่วยได้ แต่ต้องลดสิ่งสำคัญบางอย่างในชีวิต คุณตัดสินใจอย่างไร?

- **A.** รับไว้เพราะความสัมพันธ์และสิ่งที่เคยผ่านมาด้วยกันทำให้คุณมีหน้าที่รักษาความต่อเนื่องนี้  
  `ALG +0.8 ×1.0, RST +0.5 ×0.5 probe, CON +1.0 ×0.5 probe`
- **B.** วัดเวลา reserve และสิ่งที่ต้องตัดก่อน ถ้ายอมรับต้นทุนได้จึงให้คำมั่นและจัดกำลังให้ไปถึงปลายทาง  
  `ALG +0.4 ×1.0, RST +1.0 ×0.5 probe, CON +0.5 ×0.5 probe`
- **C.** เสนอความช่วยเหลือที่จำกัดและชัดเจน แต่ไม่รับพันธะระยะยาวที่อาจกลืนชีวิตส่วนอื่น  
  `ALG -0.4 ×1.0, RST +1.0 ×0.5 probe, CON +0.0 ×0.5 probe`
- **D.** ปฏิเสธรูปแบบเดิมและช่วยคิดทางใหม่ที่ไม่มีใครต้องผูกตัวเองกับภาระนี้นานขนาดนั้น  
  `ALG -0.8 ×1.0, RST +0.0 ×0.5 probe, CON +0.0 ×0.5 probe`

## DTB05 — สมุดที่ถูกเปิดโดยไม่ได้รับอนุญาต

**Domain:** `relationship_boundaries`  
**Discriminates:** Scorpion ↔ Lynx ↔ Wolverine  
**Measures:** `AGY + RSK`

คุณพบว่าคนที่อยู่ร่วมกันเปิดอ่านสมุดส่วนตัวของคุณ เขาบอกว่าเป็นห่วงและต้องการเข้าใจคุณมากขึ้น คุณตอบสนองอย่างไร?

- **A.** ย้ายสมุดและลดสิ่งที่เขาเข้าถึงได้ จากนั้นสังเกตระยะห่างโดยไม่เปิด conflict  
  `AGY -0.4 ×1.0, RSK -0.4 ×1.0`
- **B.** บอกว่าความเป็นห่วงไม่สร้างสิทธิ์เข้าถึง ล็อกพื้นที่นั้น และกำหนดว่าต้องเกิดอะไรจึงจะสร้าง trust ใหม่ได้  
  `AGY +0.4 ×1.0, RSK -0.8 ×1.0`
- **C.** เผชิญหน้าทันที ตัดช่องทางเข้าถึงทั้งหมด และพร้อมออกจากความสัมพันธ์หากอีกฝ่ายพยายามอธิบายแทนการรับผิดชอบ  
  `AGY +0.8 ×1.0, RSK +0.8 ×1.0`
- **D.** ถามว่าเขากังวลอะไร แล้วเจรจาวิธีแชร์บางส่วนโดยที่คุณยังเป็นคนเลือกขอบเขต  
  `AGY -0.4 ×1.0, RSK +0.4 ×1.0`

## DTB06 — อาหารมื้อสวยงามในสัปดาห์ที่ต้องประหยัด

**Domain:** `care_community`  
**Discriminates:** Oryx ↔ Bear  
**Measures:** `AFF + DCL + RST`

กลุ่มของคุณต้องลดค่าใช้จ่ายหลายสัปดาห์ เพื่อนคนหนึ่งเสนอให้กันทรัพยากรเล็กน้อยทำอาหารมื้อพิเศษเพื่อให้ทุกคนยังรู้สึกว่าชีวิตมีความหมาย คุณเลือกอย่างไร?

- **A.** เก็บทรัพยากรทั้งหมดไว้ก่อน ความมั่นคงของ reserve สำคัญกว่าความรู้สึกในช่วงสั้น  
  `AFF -0.4 ×0.5, DCL -0.4 ×1.0, RST +1.0 ×0.5 probe`
- **B.** ทำมื้อเล็กแต่ตั้งใจ ใช้เท่าที่ไม่กระทบ reserve เพราะความพอควรหล่อเลี้ยงความงามได้ด้วย  
  `AFF +0.8 ×0.5, DCL +0.4 ×1.0, RST +1.0 ×0.5 probe`
- **C.** ใช้ทรัพยากรส่วนนั้นดูแลคนที่กำลังรับภาระหนักที่สุดเป็นพิเศษ แม้คนอื่นจะไม่ได้รับเท่ากัน  
  `AFF +0.4 ×0.5, DCL +0.8 ×1.0, RST +0.5 ×0.5 probe`
- **D.** จัดมื้อเต็มที่เพื่อให้ทุกคนลืมความขาดแคลนสักคืน แล้วค่อยรับมือผลกระทบภายหลังร่วมกัน  
  `AFF +0.8 ×0.5, DCL +0.8 ×1.0, RST +0.0 ×0.5 probe`
