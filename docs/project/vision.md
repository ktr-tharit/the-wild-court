# Project Vision

**Status:** Draft  
**Last reviewed:** 2026-08-21

## Product statement

The Wild Court คือ interactive personality adventure ที่ถามว่า:

> หากธรรมชาติภายในของคุณพาเข้าสู่ราชสำนักแห่งสัตว์ คุณจะอยู่ในอาณาจักรใด และกลายเป็นใครในโลกนั้น?

ผลลัพธ์ไม่ใช่ตัวอักษรสี่ตัวหรือสัตว์หนึ่งตัวลอย ๆ แต่ประกอบด้วย:

- Primary Kingdom / Biome
- Secondary Kingdom เพื่อเพิ่ม nuance
- Animal Archetype
- Court role และ title
- Core desire, fear, strength และ shadow
- Compatibility และความสัมพันธ์กับ archetype อื่นในอนาคต

## Core experience

ผู้เล่นควรรู้สึกว่าได้เดินทางผ่านเหตุการณ์จริงในโลก ไม่ใช่กำลังกรอกแบบสอบถาม คำตอบแต่ละข้อสะสมเป็น continuous trait vector และถูกใช้ประเมิน animal candidates พร้อมกันตลอดเกม

## Design pillars

1. **Identity fantasy** — ทุกผลลัพธ์ต้องมี fantasy ที่น่าอยากเป็น ไม่ใช่มีเพียง predator ที่ดูเท่
2. **Psychological coherence** — ผลลัพธ์ต้องอธิบายได้จาก traits ไม่ใช่การ map คำตอบตรงเข้าสัตว์
3. **World friction** — ทุก kingdom มีคำตอบของตัวเองต่อคำถามว่า “สังคมควรถูกจัดระเบียบอย่างไรเพื่อให้คนอยู่รอด?”
4. **Narrative consequence** — คำถามเป็นเหตุการณ์ในเรื่องและต้องเข้ากับ pacing ของ act
5. **Expandable ecosystem** — เพิ่มสัตว์หรือ biome ในอนาคตได้โดยไม่รื้อระบบหลัก
6. **Empirical improvement** — เริ่มจาก designer-defined model แล้ว calibrate ด้วยข้อมูลจริงหลังเปิดใช้งาน

## Non-goals

- ไม่ใช่ MBTI reskin หรือระบบ 16 สัตว์ = 16 MBTI
- ไม่ใช่แบบประเมินทางคลินิกหรือการวินิจฉัยด้านสุขภาพจิต
- ไม่ควรอ้างความแม่นยำทางวิทยาศาสตร์เกินข้อมูลที่มี
- ไม่ควรทำให้ kingdom ใดเป็น good/evil อย่างตรงไปตรงมา
- ไม่ควรให้คำตอบหนึ่ง “ดีที่สุด” จนผู้เล่นพยายามโกงเพื่อให้ได้ผลนั้น

## Success criteria สำหรับ design prototype

- สัตว์ใน biome เดียวกันแตกต่างกันอย่างอธิบายได้
- ผู้เล่นสองคนที่ introverted เท่ากันยังสามารถได้คนละ kingdom
- ทุก answer option วัด trait และไม่มี option ที่เห็นได้ชัดว่า map ไปสัตว์ใด
- แบบทดสอบต้นแบบแยก top candidates ได้ภายในประมาณ 16–20 ข้อ
- ผลลัพธ์มีคำอธิบายที่ผู้เล่นอยากบันทึกหรือแชร์
